# CapacitacionKodigo

Repositorio de prácticas y actividades de la **capacitación "Transformación Digital para la Docencia Técnica"** (Kodigo / INSAL 2026).

Este repositorio recopila los ejercicios y proyectos realizados durante el curso, enfocados principalmente en **desarrollo web frontend** (HTML + CSS) y **bases de datos** (SQL).

## Estructura del Repositorio

### 📁 `html_css/`
Práctica básica de HTML5 y CSS3.  
- **Objetivo**: Crear una receta estilizada (`Simple Omelette Recipe`).  
- Incluye: estructura semántica, listas, tablas, imágenes y estilos responsivos.  
- **Archivo principal**: [`index.html`](html_css/index.html) + [`css/style.css`](html_css/css/style.css)

### 📁 `flex_grid/`
Demostración práctica de **Flexbox** y **CSS Grid**.  
- **Objetivo**: Entender y aplicar layouts modernos de manera flexible.  
- **Archivo principal**: [`index.html`](flex_grid/index.html) + [`style.css`](flex_grid/style.css)

### 📁 `landingPage/`
Landing page completa y moderna sobre **historia de los videojuegos** (siglo XXI).  
- **Tecnologías**: HTML5, CSS3 avanzado (animaciones, grid, efectos visuales).  
- Incluye: navegación, banner hero, timeline de eras, grid de juegos icónicos, etc.  
- **Archivo principal**: [`index.html`](landingPage/index.html) + [`style.css`](landingPage/style.css)

### 📁 `tareaFrontend/`
**Tarea final de Frontend** – Versión avanzada e interactiva de la landing page.  
- Incluye JavaScript para navegación por secciones (SPA-like).  
- Diseño pulido con tema de **GameVerse**.  
- **Archivos principales**: [`index.html`](tareaFrontend/index.html), [`style.css`](tareaFrontend/style.css) y un icono.

### 📁 `Base_Datos/`
Prácticas de **Bases de Datos Relacionales** (PostgreSQL).  
- **Archivo**: [`consultas_accommodations.sql`](Base_Datos/consultas_accommodations.sql)  
- Contenido: 
  - INSERTs complejos (con CTEs)
  - SELECTs con JOINs, LEFT JOINs
  - UPDATEs y DELETEs
  - Funciones de agregación (SUM, AVG, COUNT, etc.)
  - Consultas sobre un esquema de **gestión de alojamientos turísticos**
