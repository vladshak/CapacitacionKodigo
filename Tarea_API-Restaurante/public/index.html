API Restaurante

Gestiona usuarios, mesas y reservaciones con autenticación JWT y roles.

Ver documentación Contactar

Endpoints principales

  • POST /api/auth/register — Registro cliente
  • POST /api/auth/login — Iniciar sesión
  • GET /api/auth/perfil — Perfil usuario
  • GET /api/mesas — Listar mesas
  • POST /api/reservaciones — Crear reserva

Características

Seguridad

JWT con roles para controlar accesos de clientes y administradores.

Reservaciones

Validación de disponibilidad por fecha y hora antes de confirmar.

Admin

Crear, actualizar y desactivar mesas; ver y cambiar estados de reservas.
